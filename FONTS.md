| Lato-Regular / Lato-Black / Lato-MediumItalic SDF | Lato 2.015 — Łukasz Dziedzic |
| Nunito-Regular / Nunito-Black SDF | Nunito — Copyright 2014 The Nunito Project Authors |
| Oswald SDF | Oswald — Copyright 2016 The Oswald Project Authors |
| Knights Quest SDF | Kurale — Copyright 2013 The Kurale Project Authors (substitute: original has no Cyrillic) |
| vinque rg SDF | Ruslan Display — Copyright 2011 Oleg Snarsky, Denis Masharov, Vladimir Rabdu (substitute: original has no Cyrillic) |

The original Latin glyphs of all fonts are unchanged.
